# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and welcoming, give and accept constructive feedback
gracefully, and don't harass anyone.

URL Monitor deals with a sensitive subject. Discuss monitoring, accountability
and adult content without shaming anyone, and never share anyone's personal
browsing data.

## Reporting

If someone's behaviour is unacceptable, report it privately to the maintainer
through the contact details on the [SNBDev GitHub profile](https://github.com/snb-dev).
Reports are handled confidentially.
